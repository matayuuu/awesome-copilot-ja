# Copilot Library 日本語版

このリポジトリのリソースを、日本語の説明で検索し、お気に入りに保存するローカルアプリです。公式サイトとは独立して動作します。リソース本体、インストール先、識別子は変更しません。

## 起動

Node.js 22 系と npm が必要です。Windows の PowerShell、Node.js 22.13.0、npm 10.9.2 で実行を確認しています。リポジトリのルートで実行してください。

```powershell
npm ci
npm run local:dev
```

ブラウザーで **http://127.0.0.1:4317/** を開きます。停止は起動したターミナルで `Ctrl+C` です。サーバーは `127.0.0.1` にのみバインドします。

ビルドと起動を分ける場合は、次のコマンドを使います。

```powershell
npm run local:build
npm run local:preview
```

`local-app\dist\index.html` に、CSS、JavaScript、カタログを内包した単一の HTML を生成します。実行時の外部通信、翻訳 API、認証は不要です。初回の依存関係の取得と、公式ページ・ソースへのリンクにはインターネット接続が必要です。HTML の直接表示ではブラウザーごとに保存動作が異なるため、上記のローカルサーバーで使用してください。HTML を配布する場合は、同じ出力先の `LICENSE.txt` も添付してください。

ポートを変更する場合は、PowerShell で設定してから起動します。**ホスト名やポートを変えるとお気に入りの保存領域も変わります。**

```powershell
$env:PORT = '4318'
npm run local:preview
```

## 使い方

| 操作 | 動作 |
| --- | --- |
| 検索 | 日本語の説明、原文、名前、識別子、タグを検索。スペース区切りは AND 検索 |
| カテゴリー | 種類で絞り込み。同じカテゴリーをもう一度押すと解除 |
| ☆ / ★ | お気に入りに保存、または保存を解除 |
| 保存済み | 保存したリソースだけを表示。検索とカテゴリーを併用可能 |
| 並べ替え | 名前の昇順・降順、更新が新しい順、保存が新しい順。日時不明・未保存は後ろに表示 |
| 説明を読む | 日本語の全文、原文、タグ、公式ページ・ソースへのリンクを表示 |
| 保存をエクスポート | お気に入りの識別子と保存日時を JSON に書き出す |
| インポート | バックアップを既存データへ統合。同じ項目は新しい保存日時を保持 |

`/` キーで検索欄に移動し、`Escape` で詳細を閉じます。右上のボタンでライト／ダークテーマを切り替えます。テーマは URL の `scoutTheme` パラメーターに反映されます。

Learning Hub の記事本文やリソース本体の全文翻訳は対象外です。公式サイトの最新状態を自動取得するのではなく、チェックアウトしたリポジトリからカタログを作ります。データの生成日とコミット識別子を画面下部に表示します。

既存の日本語説明474件はそのまま使い、残り602件は `translations\` の JSON で翻訳を管理します。説明メタデータがない15件は本文冒頭に基づく要約とし、詳細画面で明示します。AI による翻訳・要約のため、重要な用途や制約は原文も確認してください。

各翻訳には元の説明文の SHA-256 を記録しています。英語の説明が追加・変更された場合、未翻訳または古い翻訳のままビルドすることはできません。

```powershell
npm run website:data
node eng\export-local-catalog.mjs
```

生成された `website\public\data\local-source.json` の `key`、`description`、`sourceHash` を確認し、対応する `local-app\translations\*.json` を更新してから `npm run local:build` を実行します。生成された HTML や JSON を直接修正しても、次のビルドで上書きされます。翻訳更新では原文の意味を確認し、ハッシュだけを更新しないでください。

一覧から脱落していた2件の Skill は、既存の説明を保持したまま欠けていた `description:` キーを補っています。

## 保存先と制限

お気に入りはブラウザーの `localStorage` の `awesome-copilot-ja:favorites:v1` に保存されます。アカウント間・端末間の同期は行いません。同じブラウザー・同じオリジンの別タブでは変更を反映します。複数タブから全く同時に書き込んだ場合は、最後の書き込みが優先される場合があります。

ブラウザーのサイトデータ削除やプライベートブラウジングの終了で失われることがあります。必要なデータは JSON でバックアップしてください。カタログからなくなったリソースの保存情報はバックアップに保持されますが、カードには表示されません。

読み取り不可能な保存データは上書きせず、画面にエラーを表示して保存操作を無効にします。容量制限などで書き込みに失敗した場合も、保存成功として扱いません。インポートは形式と日時を検証し、5 MB を超えるファイルは受け付けません。

## 検証

```powershell
npm run local:build
npm run local:test
npx playwright install chromium
```

別のターミナルで `npm run local:preview` を起動してから、ブラウザー検証を実行します。

```powershell
npm run local:test:browser
```

ブラウザー検証ではユーザーの通常のブラウザープロファイルを使わず、独立したテスト用プロファイルを使います。全件の日本語説明、10カテゴリー、検索、4種類のソート、再読み込み後の保存、別タブ同期、JSON 入出力、破損データ・書き込み拒否、モバイル表示、ライト／ダークテーマ、axe-core によるアクセシビリティ検査を確認します。画像と結果は既定で `reports\local-catalog\` に出力されます。
