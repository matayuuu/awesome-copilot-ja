# Chromium Control Canvas プラグイン

実際の Chromium ウィンドウを開き、Copilot canvas のコントロールパネルと agent actions から移動・操作できます。

## インストール

``bash
copilot plugin install chromium-control-canvas@awesome-copilot
``
