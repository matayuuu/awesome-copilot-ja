# Copilot SDK プラグイン

複数のプログラミング言語で GitHub Copilot SDK を使ったアプリケーションを構築します。AI 搭載アプリケーションの作成に役立つ C#、Go、Node.js/TypeScript、Python 向けの包括的な instructions を含みます。

## インストール

```bash
# Using Copilot CLI
copilot plugin install copilot-sdk@awesome-copilot
```
