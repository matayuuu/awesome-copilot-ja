# Jupyter Notebooks プラグイン

インタラクティブな GitHub Copilot canvas で Jupyter notebook の作成、編集、実行、保存、チェックポイント作成を行います。

## インストール

```bash
copilot plugin install jupyter-notebooks@awesome-copilot
```
