# Windows App Storage Inspector & Cleanup Plugin

Windowsアプリケーションのストレージを調査し、ローカルディスクの使用状況を把握して、承認済みのクリーンアップ対象を安全にごみ箱へ移動します。

## インストール

```bash
copilot plugin install windows-app-storage-inspector-cleanup@awesome-copilot
```
