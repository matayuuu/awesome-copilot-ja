# Modernization Workflow プラグイン

GitHub Copilot Modernize CLI の
Assess、Plan、Execute ワークフローを可視化し、案内するインタラクティブな canvas です。.NET、Java、C++ アプリケーション
リポジトリに対応します。

## インストール

```bash
copilot plugin install modernization-workflow@awesome-copilot
```
