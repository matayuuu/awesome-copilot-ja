# Power Apps Component Framework (PCF) Development Plugin

モデル駆動型アプリとキャンバスアプリ向けに、Power Apps Component Frameworkを使ったカスタムコードコンポーネントを開発するための総合ツールキットです。

## インストール

```bash
# Using Copilot CLI
copilot plugin install pcf-development@awesome-copilot
```
