# 必要なコンテキスト

私の質問に答える前に、確認する必要があるファイルを教えてください。

## 私の質問

{{question}}

## 指示

1. 私の質問に基づき、調査が必要なファイルを一覧にする
2. 各ファイルが関係する理由を説明する
3. この会話ですでに確認したファイルを記載する
4. 何が不確かなのかを明らかにする

## Output Format

```markdown
## 必要なファイル

### 必ず確認するファイル（正確な回答に必須）
- `path/to/file.ts` — [必要な理由]

### できれば確認するファイル（回答の完全性に役立つ）
- `path/to/file.ts` — [役立つ理由]

### 確認済み
- `path/to/file.ts` — [会話の前半で確認済み]

### 不確かな点
- [コードを見ないと分からないこと]
```

これらのファイルを提示したら、もう一度質問します。
